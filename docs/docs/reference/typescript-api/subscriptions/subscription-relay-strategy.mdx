## SubscriptionRelayStrategy

<GenerationInfo sourceFile="packages/core/src/config/subscriptions/subscription-relay-strategy.ts" sourceLine="74" packageName="@vendure/core" since="3.8.0" />

Determines how a published subscription payload reaches the server instances which have
subscribers. The default [InMemorySubscriptionRelayStrategy](/reference/typescript-api/subscriptions/in-memory-subscription-relay-strategy#inmemorysubscriptionrelaystrategy) delivers within a single
process; use the [RedisSubscriptionRelayStrategy](/reference/typescript-api/subscriptions/redis-subscription-relay-strategy#redissubscriptionrelaystrategy) for a multi-instance deployment or when
publishing from the worker.

:::info

This is configured via the `apiOptions.subscriptions.relayStrategy` property of your
VendureConfig.

:::

```ts title="Signature"
interface SubscriptionRelayStrategy extends InjectableStrategy {
    publish(message: RelayedSubscriptionMessage): Promise<void>;
    subscribe(key: string, listener: SubscriptionRelayListener): Promise<() => Promise<void>>;
}
```
* Extends: [`InjectableStrategy`](/reference/typescript-api/common/injectable-strategy#injectablestrategy)
