The default [SubscriptionRelayStrategy](/reference/typescript-api/subscriptions/subscription-relay-strategy#subscriptionrelaystrategy), which delivers messages within a single process.
Events published by another server instance or by the worker are not delivered - configure the
[RedisSubscriptionRelayStrategy](/reference/typescript-api/subscriptions/redis-subscription-relay-strategy#redissubscriptionrelaystrategy) for that.
